❓ Quick Practical FAQ
Q: Will it work if the classroom has zero Wi-Fi or Internet?
Yes. Every single asset, algorithm engine, code parser, and icon is stored locally on this USB. It never calls any external server.
Q: How do I enter full-screen SmartBoard presentation mode?
Press F11 on your keyboard or tap the Fullscreen button on the top-right toolbar.
Q: How do I pre-set or edit my offline license key?
Open license.json in the USB root folder with Notepad. Change the licenseKey or organization details and save. TreadCode auto-activates on launch without needing internet.
Q: Where is my drawing or code saved?
Everything you draw or code is automatically saved in your browser's persistent offline storage. You can also export as PNG or JSON anytime.
