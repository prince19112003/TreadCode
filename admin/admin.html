FlowTrace User Manual

1. License Key Generate Kaise Karein?

"Licenses" tab par jayein. **Generate Enterprise License** card me target institution ya college ka naam enter karein, aur unke computer labs ke liye systems limit specify karein (e.g. 30). **Generate Key** par click karte hi ek random unique key create ho jayegi.

2. Student Computer Par Active Kaise Hoga?

Jab student FlowTrace desktop app open karega, use ek Apple-style validation window dikhegi. Unhe generated key copy-paste karke **Activate Software** click karna hoga. Validation complete hone par system register ho jayega.

3. Device Lock (HWID) Kaise Kaam Karta Hai?

Ek key duplicate share na ho sake, isliye user key enter karte hi unka hardware interface ID database me automatically lock ho jata hai. Ek user se dusre user par duplicate validation run karne par license access direct deny show hoga agar limit exceed ho chuki hai.

4. Installation Block / Revoke Kaise Karein?

Agar kisi key ka access cancel karna hai, toh license key ke row me **Revoke Key / Block Key** button click karein. Status instantly **Blocked** ho jayega aur current users ka software block screen lock state me chala jayega.
